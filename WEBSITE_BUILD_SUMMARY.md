## What Service Pages Include

Each page is optimized for:
- ✅ SEO (keywords in title, H1, first 100 words)
- ✅ Conversions (multiple CTAs, clear benefits)
- ✅ User Experience (clear sections, scannable content)
- ✅ Mobile (responsive design, touch-friendly buttons)
- ✅ Performance (optimized components, fast load)

### Page Structure (Same for All):
1. **Hero Section** (30-50 words)
   - Eyebrow category
   - H1 headline
   - Description
   - 2 CTAs

2. **Benefits Section** (3-6 benefits)
   - Concrete metrics
   - Clear descriptions
   - Grid layout

3. **Process Section** (5-7 steps)
   - Numbered steps
   - Clear flow
   - Visual progression

4. **Tech Stack** (8-12 technologies)
   - Categorized by function
   - Card layout
   - Easy to scan

5. **Pricing Section** (2-3 tiers)
   - Starter, Growth, Enterprise
   - Clear pricing
   - Feature lists
   - CTAs

6. **FAQs** (5-10 questions)
   - Common questions
   - Concise answers
   - Expandable/collapsible

7. **Final CTA** (1 button)
   - Call to action
   - Centered
   - Bold design
